# Support

## Planoly product help

For questions about your Planoly account, plans, connected channels, or the app itself:

- Help center: https://support.planoly.com
- Product: https://www.planoly.com

## MCP server help

- Setup and client configuration: see the [README](./README.md) and [docs/](./docs).
- Common errors: [docs/troubleshooting.md](./docs/troubleshooting.md).
- Bugs and feature requests for the MCP server: [open an issue](https://github.com/Planoly/planoly-mcp/issues) — include the client you're using, the tool called, and the error text. Never include access tokens.

## Security issues

See [SECURITY.md](./SECURITY.md) — please don't report vulnerabilities in public issues.
